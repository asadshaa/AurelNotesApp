# Aurel Keyboard & Markdown Shortcuts

| Shortcut | Description | Result |
| :--- | :--- | :--- |
| `# ` | Heading 1 | Large section heading |
| `## ` | Heading 2 | Medium section heading |
| `### ` | Heading 3 | Subsection heading |
| `- ` or `* ` | Bullet list | Unordered list item |
| `1. ` | Numbered list | Ordered numerical list |
| `- [ ] ` | Task checklist | Interactive checkbox item |
| `> ` | Blockquote | Editorial pull-quote callout |
| ```` | Code block | Monospaced syntax box |
| `[[` | Backlink | Wiki-style note link popup |
